# Открытые вопросы

1. Лист `Кабели` файла `TELCORD_73_варианта_кабеля_с_available.xlsx` является источником конечных физических вариантов кабеля, их постоянных `key`, признака `available` и кабельных цен. Цены остальных компонентов пока импортируются из `TELCORD_цены_полный_варианты_кабеля_2026-08-21.xlsx`. Цены `full_black` отсутствуют и остаются nullable до получения номенклатуры.
2. В файле не заданы коды волокна для G.652.D, G.655, G.657.A2, G.657.B3, OM1, OM2 и OM5. Временно используются значения `SM(652D)`, `SM(655)`, `SM(A2)`, `SM(B3)`, `MM621`, `MM501`, `MM505`; их нужно подтвердить до выпуска артикулов.
3. Не определено, должны ли выводы `(lead)` попадать в название. Сейчас они входят только в артикул.
4. Для MTRJ спецификация показывает `/U`, но одновременно устанавливает для многомода только `/PC`. Engine применяет общее правило полировки; нужен ответ, означает ли `/U` для MTRJ отдельное исключение.
5. Для `full_black` цена компонентов nullable по требованию. Расчёт должен возвращать ошибку, если выбранный black-компонент не имеет цены; отдельные black price keys готовы к добавлению после получения номенклатуры.
6. В новом перечне есть конструкции `DUPLEX FLAT`, но отдельный утверждённый формат артикула и названия для них не задан. Варианты хранятся и доступны для выбора, однако большинство из них пока имеют `price = null`, поэтому расчёт корректно сообщает об отсутствии цены до генерации результата.
